# Internationalization

Aculect Mail uses the `onesmtp` text domain for all plugin strings.

## Release Checklist

- Keep plugin headers aligned:
  - `Text Domain: onesmtp`
  - `Domain Path: /languages`
- Wrap new user-facing PHP strings in WordPress translation functions such as `__()`, `esc_html__()`, `esc_attr__()`, `_x()`, `_n()`, `esc_html_e()`, or `esc_attr_e()`.
- Pass `onesmtp` as the text-domain argument.
- Regenerate the translation template before release packaging:
  - `composer i18n:make-pot`
- Commit `languages/onesmtp.pot` when strings change.

## Validation

Run:

```bash
composer i18n:make-pot
git diff -- languages/onesmtp.pot
```

The generator scans PHP files outside `vendor/`, `node_modules/`, `build/`, and `tests/`.
It records literal strings that use the `onesmtp` text domain and writes the template to `languages/onesmtp.pot`.

## Non-Goals

- Do not commit compiled `.mo` files.
- Do not ship placeholder translations.
- Do not mix localization updates with unrelated behavior changes.
