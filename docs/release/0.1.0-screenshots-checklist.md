# Aculect Mail 0.1.0 Screenshots Checklist

Use this checklist to capture WordPress.org-ready screenshots after the 0.1.0 admin UI is available in a release test site.

## Capture Requirements

- Use a clean WordPress test site running Aculect Mail 0.1.0.
- Use neutral sample domains, email addresses, and provider names.
- Do not show real API keys, tokens, secrets, customer addresses, message bodies, or production logs.
- Prefer cropped admin screenshots that keep the Aculect Mail workflow readable without exposing unrelated site data.
- Match screenshot numbering to the `readme.txt` Screenshots section.

## Screenshot List

1. Provider setup screen with provider type, priority, weight, and active state visible.
2. Provider test email result showing a safe success or failure response.
3. Email log list showing message status, provider, attempt number, and delivery result.
4. Manual resend action with optional provider override.
5. Retry scheduler warning shown when Action Scheduler is unavailable.
6. Release package file list or release workflow artifact evidence showing production packaging.

## Pre-Publish Review

- Confirm no screenshot contains raw credentials or sensitive message content.
- Confirm visible copy does not mention competitor products.
- Confirm the UI shown matches the 0.1.0 release branch, not a later branch.
- Confirm each screenshot has a corresponding `readme.txt` caption.
- Confirm image filenames follow the WordPress.org sequence, such as `screenshot-1.png`.
